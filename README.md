# Vrinda Store Data Analysis Project

### Project Overview
*   *Objective:* In-depth sales data analysis to understand Vrinda Store's business performance, customer buying behavior, and revenue trends.
*   *Purpose:* To provide data-driven insights that help improve future sales strategy and overall business growth.

### Key Insights & Analysis
*   *Top Channels:* Identified the highest contributing sales channels (e.g., Amazon, Myntra, Flipkart).
*   *Customer Demographics:* Analyzed which gender and age group are driving maximum purchases.
*   *Regional Performance:* Mapped out the top-performing states and cities in terms of sales volume.
*   *Monthly Trends:* Tracked peak sales months to understand seasonality patterns.

### Tools Used
*   *Microsoft Excel:* Used for advanced data cleaning, processing raw data, and performing initial exploratory analysis.
*   *Pivot Tables & Charts:* Created dynamic summaries and visual charts to pinpoint hidden data trends.
